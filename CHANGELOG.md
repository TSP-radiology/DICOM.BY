# История изменений / Changelog

## [0.4.3] — 2026-11-25
### Защита распространения, подпись Ed25519 и центр доверия
- **Офлайн-регистрация бесплатной версии (`Ed25519`):** добавлена локальная криптографическая проверка регистрационного ключа `DICOMBY-1....` в [`DICOM-BY.exe`](https://dicom.by/get-key/) без сетевых запросов при обработке снимков.
- **Подписанные обновления и реестр доказательств:** манифест обновлений `windows-x64.json` и паспорт `RELEASE_MANIFEST.json` (`schema_version = 2.0`) теперь подписываются закрытым ключом **Ed25519** с проверкой встроенным публичным ключом и защитой от отката.
- **Закрытие исходников движка и открытый верификатор (MIT):** публичный репозиторий переведён в модель Trust-Hub — спецификация `admission_v5.json`, подписанный `RELEASE_MANIFEST.json` и открытый верификатор `verify/dicom_by_verify.py` (MIT) доступны для независимого аудита.
- **Прозрачность метрик и /get-key/:** добавлена страница регистрации [`dicom.by/get-key/`](https://dicom.by/get-key/), таблица формул и числителей/знаменателей `S6B-BLIND-TEST` в `README.md` и на `/evidence/`.

## [0.4.2] — 2026-11-25
### Исправления и документация
- **Исправлен экспорт ZIP на системах Windows с локалью `CP1252` (США/ЕС):** `build_clean_zip_export` теперь вызывает `%SystemRoot%\System32\tar.exe` внутри временного каталога подготовки с ASCII-именем `_export.zip` и переносит архив в целевой путь UTF-16 средствами Win32 API.
- **Корпоративные формулировки экспорта ZIP:** из интерфейса и подсказок `DICOM-BY.exe` убраны упоминания личных мессенджеров и почты — оставлены рекомендации по разрешённым каналам передачи медицинской организации.
- **Позиционирование и открытая проверяемость:** уточнено разделение `PROVEN` / `SCREENED` / `REVIEW` / `REFUSED`, раскрыты разные знаменатели `S6B-BLIND-TEST` (`all` vs `released`) и `G5M FAIL` в `README.md`, добавлен аудит источников `TCIA` / `PTKB` / `US Census 2010` в `DATA_SOURCES.md` и Open Graph превью на `dicom.by`.

## [0.4.1] — 2026-11-25
### Новое в настольном приложении и установщике
- **Просмотр списка отложенных и неподдерживаемых файлов:** карточки «На проверку врачу» и «Не поддерживается» открывают окно с конкретными файлами, понятным объяснением причины на русском языке (вкл. пустой `PatientID`) и кнопкой «Показать в папке».
- **Экспорт чистого ZIP в 1 клик:** сборка архива только из очищенных снимков (без `_quarantine`, `.refused.json` и `ОТЧЁТ.txt`; сертификаты `.deid.json` подключаются опционально) с подсказкой по объёму архива для разрешённого канала передачи.
- **Безопасная подсистема обновлений:** проверка манифеста по HTTPS (`https://dicom.by/updates/windows-x64.json`) с обязательной проверкой `SHA-256` через Windows CNG (`BCrypt`) и возможностью отключения для изолированных контуров.
- **Установщик Windows:** поддержка обновления поверх `0.4.0` (`AppMutex`, `CloseApplications=yes`, `RestartApplications=yes`), обновлены баннеры мастера под `0.4.1`.

## [0.4.0] — 2026-11-25
### Ядро и инфраструктура
- Замороженный выпуск ядра `0.4.0` (`admission_v5.json`, `attribute_policy_v1.json`, `private_safe_v2.json`, каскад OCR + вторая линия по серии).
- Слепой контрольный зачёт **S6B-BLIND-TEST** на 428 сериях: **98,16 %** по полным сериям (`97,75 %` по всем), **0** новых ошибок `dciodvfy`, **0** утечек скрытых пикселей, **HIPAA-Z = 0 / 1 116 405**, **9,53 об/с**.
- Первое брендированное настольное приложение Windows (`DICOM-BY.exe` на Win32 + WebView2) и установщик `DICOM-BY-0.4.0-Setup.exe`.
- Независимый криптографический верификатор `dicom-verify` (`--cert`, `--audit`).
